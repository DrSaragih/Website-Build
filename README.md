# 23 Paskal — A place for every story

Independent responsive website concept with four connected layers: The Mall, Directory, What's Next, and Shopping Program. Includes scroll parallax, category filtering, search, detail dialogs, mobile navigation, and reduced-motion support.

## Development

Node.js 20.19+ or 22.12+ is required.

```sh
npm ci
npm run dev
```

Production: `npm run build`; inspect using `npm run preview`.

Locally bundled SVG artwork is illustrative, not a verified architectural depiction of 23 Paskal. Event and rewards content is explicitly conceptual. Tenant discovery cards represent categories, not a verified tenant list. Replace these with approved mall assets and confirmed business information before publication. Higgsfield was unavailable during implementation. Reference URL could not be retrieved from this environment.
